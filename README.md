# Крокодил — 5 игроков

Android-игра для пяти участников. Настройка имён и длительности хода, простые русские слова, таймер, очки и автоматическое переключение игроков.

## Сборка
GitHub Actions запускает сборку при каждом push в `main` или вручную через вкладку Actions. APK доступен в Artifacts завершённого запуска.
